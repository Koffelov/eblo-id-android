# eblo.id — неофициальный Android-клиент

> **Неофициальное приложение.** Не связано с [eblo.id](https://eblo.id) и его авторами.

Скачать: **[последний релиз](https://github.com/Koffelov/eblo-id-android/releases/latest)** → файл `eblo-id-<версия>.apk`.

## Что это

Нативное Android-приложение в стиле eblo.id: тёмная тема сайта, его шрифт Handjet, зелёные акценты,
нижняя панель «Лента · Видосы · + · Уведомления · Профиль».

| Экран | Как сделан |
|---|---|
| Лента (Лента / Подписки, фильтры сортировки, периода и типа, #теги) | нативный, `/api/feed` |
| Пост: картинки, альбомы, видео, аудио, файлы, описание со ссылками и #тегами | нативный, документированный `/api/public/post/<код>` |
| Оценки поста ▲▼, комментарии с ответами и оценками, написание комментариев | нативный, `/api/post/<код>/vote`, `/api/post/<код>/comments`, `/api/comment/<id>/vote` |
| Профиль: аватар, значки, Twitch/Telegram, счётчики, сетка публикаций, подписка | нативный, страница `/@логин` + `/api/profile/<логин>/uploads`, `/follow` |
| Уведомления | нативный, `/api/notifications/list` |
| Поиск пользователей и постов | нативный, `/api/search/all`, `/api/feed?q=` |
| Видосы (предложка видео на стримы) | нативный список, `/api/videos/list`; видео открываются в YouTube |
| Просмотр фото (зум, листание, GIF/WebP-анимация) и видео | нативный |
| **Вход через Twitch** | страница сайта внутри приложения |
| **Новый пост** (загрузка файлов) | страница сайта `/new` внутри приложения, без шапки сайта; файлы — через системный выбор Android |

Почему вход и публикация остаются страницами сайта:
- Twitch OAuth у eblo.id возвращает только на `https://eblo.id/auth/twitch/callback`, поэтому вход должен завершиться в том же хранилище cookie, что использует приложение. Внешний браузер не подходит: его cookies в приложение не попадают.
- Публикация идёт через загрузчик сайта (порциями, с CSRF-токеном и проверкой Cloudflare Turnstile). Повторять его вне сайта ненадёжно.

Нативные экраны и веб-экраны используют одно хранилище cookie, поэтому после входа всё работает от вашего аккаунта.

### Про API сайта

Документирован только публичный API на `/uploaders` (чтение поста, нескольких постов, лимиты загрузки) и API загрузки по личному ключу.
Остальное — внутренние JSON-запросы, которые использует сам сайт. Они не описаны и могут измениться.
Если это случится, экран покажет ошибку с кнопкой «Открыть на сайте». Такой экран будет работать как страница сайта, пока не выйдет обновление приложения.

## Установка на Android

1. На телефоне откройте [Releases](https://github.com/Koffelov/eblo-id-android/releases/latest) (репозиторий приватный — войдите в GitHub в браузере телефона) и скачайте `eblo-id-<версия>.apk`.
2. Откройте файл. Если Android спросит — разрешите «Установка неизвестных приложений» для браузера/файлового менеджера.
3. Запустите «eblo.id (неоф.)» → вкладка «Войти» → «Войти через Twitch».

Чтобы ссылки `https://eblo.id/...` из Telegram и т.п. открывались в приложении: *Настройки → Приложения → eblo.id (неоф.) → Открывать по умолчанию → Добавить ссылку → eblo.id*.

## Обновления

Новые версии публикуются в [Releases](https://github.com/Koffelov/eblo-id-android/releases). Скачайте APK и установите поверх: все релизы подписаны одним постоянным ключом, поэтому вход и данные сохраняются.
Чтобы получать уведомления: *Watch → Custom → Releases* на странице репозитория.

## Сборка (только GitHub Actions)

Локально ничего ставить не нужно: Android SDK и JDK есть на раннерах GitHub. Сторонних библиотек нет, только Android SDK.

| Workflow | Когда | Что делает |
|---|---|---|
| [`android.yml`](.github/workflows/android.yml) | push в `main`, pull request | debug-APK (только для тестов, ставится отдельным приложением «eblo.id DEBUG») и подписанный release-APK как артефакты |
| | тег `v*` или *Run workflow* с галочкой «Опубликовать» | то же + GitHub Release с подписанным APK |
| [`smoke-test.yml`](.github/workflows/smoke-test.yml) | вручную | эмулятор Android + живой сайт под гостем: лента, пост, профиль, поиск, вкладки, «Назад», офлайн, вход через Twitch внутри приложения, выбор файлов, cookie после перезапуска. Без входа и без публикаций |

`versionCode` = 100 + номер запуска, поэтому каждая следующая сборка ставится поверх предыдущей.

### Подпись

Release подписывается постоянным ключом PKCS#12 из секретов репозитория:
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Ключ и пароли не коммитятся. Workflow сверяет SHA-256 сертификата
(`e203df76294e0157675b63cae0fcddff8c7fb68a53c382bd0c5b62db916eb295`) и падает, если APK подписан другим ключом.
Без секретов релиз не публикуется.

Оригинал ключа хранится у владельца вне репозитория. **Сделайте его резервную копию.** Без него обновить установленную версию поверх не получится: придётся удалить приложение и войти заново.

## Известные ограничения

- Внутренний API сайта не документирован: после изменений на сайте отдельные экраны могут временно открываться как страница сайта.
- Нет push-уведомлений: у сайта нет для этого API. Уведомления видны во вкладке «Уведомления».
- Вход через Twitch во встроенном окне: входите **логином и паролем Twitch** (плюс код 2FA, если включён). Кнопка «Continue with Google» на странице Twitch не сработает: Google запрещает вход во встроенных окнах. Apple, Amazon и passkey тоже могут не работать. Если Twitch когда-нибудь запретит вход во встроенных окнах, войти в приложении не получится: перенести сессию из внешнего браузера нельзя.
- Проверка Cloudflare «я не робот» может появиться при действиях. Тогда приложение предложит открыть пост на сайте и пройти её там.
- Не реализованы нативно: закладки, жалобы, редактирование и удаление своих постов и комментариев, настройки профиля, игры и Chatterino+. Они доступны через «Открыть на сайте» и «Редактировать профиль».
- Не TWA: у eblo.id нет `assetlinks.json`, поэтому ссылки eblo.id открываются в приложении только после ручного включения (см. выше).
- Скачивание файлов на Android 7–9 передаётся браузеру.

## Что проверено

Автоматически, на эмуляторе Android 15 с живым eblo.id, под гостем ([smoke-test.yml](.github/workflows/smoke-test.yml)), 31 проверка:
лента и первый пост совпадают с `/api/feed`; открытие поста из ленты и по ссылке; комментарии; «Назад»; профиль; поиск; «Видосы»;
приглашения войти для гостя; вход открывает страницу Twitch внутри приложения; cookie сессии eblo.id сохраняется после
принудительной остановки приложения; «Новый пост» открывает `/new` без шапки сайта; системный выбор файлов отдаёт файл странице;
экран без интернета и повтор после подключения; отсутствие падений в logcat.

**Не проверено** (нужен реальный аккаунт, тестовые посты от вашего имени не публиковались): сам вход логином и паролем Twitch,
оценки, комментарии, подписки и уведомления от вашего имени, публикация поста с вложениями.
